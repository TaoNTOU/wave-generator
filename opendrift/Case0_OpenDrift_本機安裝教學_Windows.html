OpenDrift 本機安裝教學

Windows 11／Miniforge Prompt 版。從 Git 下載、切換資料夾、建立 OpenDrift 環境到安裝與測試，全程只使用 Miniforge Prompt。

0. 這份教學採用哪一種安裝？

採用官方建議的 Miniforge + Git + 可編輯安裝。這種方式適合之後直接查看官方案例、修改程式，或使用 git pull 更新 OpenDrift。

本教學假設你想把 OpenDrift 放在：
F:\opendrift\program

如果你想放在別的硬碟，只要把後面的路徑換掉即可，例如 C:\OpenDrift 或 E:\Model\OpenDrift。

1. 安裝 Miniforge

先安裝 Miniforge。安裝完成後，Windows 開始功能表會出現 Miniforge Prompt。

本教學後續全部使用 Miniforge Prompt。
Miniforge Prompt 是 CMD 介面，因此：
用途指令
列出資料夾內容dir
跨磁碟機切換資料夾cd /d F:\資料夾
確認 mambamamba --version

安裝完成後，開啟 Miniforge Prompt，先檢查：

輸入位置：Miniforge Prompt

mamba --version

如果出現版本號，例如：

2.5.0

代表 Miniforge 與 mamba 已經可以正常使用。

OpenDrift 官方文件目前仍將 Miniforge／Mambaforge 搭配 Git 的方式列為推薦安裝法。

2. 安裝 Git for Windows

Git 用來把 OpenDrift 官方原始碼從 GitHub 下載到你的電腦。若 Miniforge Prompt 出現：

git : 無法辨識 'git' 詞彙是否為 Cmdlet、函數、指令檔或可執行程式的名稱。

就代表目前電腦尚未安裝 Git，或 Git 尚未加入 Windows 的 PATH。

步驟 2-1：下載 Git for Windows

開啟官方下載頁：

https://git-scm.com/download/win

下載一般的 64-bit Git for Windows Setup。

步驟 2-2：執行安裝程式

安裝過程大多維持預設值即可。最重要的是 Git 必須能從 Miniforge Prompt 或 Command Prompt 使用。

安裝畫面建議
Destination Location維持預設，例如 C:\Program Files\Git
Select Components維持預設
Choosing the default editor可維持預設，或選自己習慣的編輯器
Adjusting the name of the initial branch維持預設即可
Adjusting your PATH environment請保留可從 command line / Miniforge Prompt 使用 Git 的選項
其餘選項一般維持預設即可
安裝完成後不要直接沿用原本已開啟的 Miniforge Prompt。
請把原本的 Miniforge Prompt 關掉，再重新開一個新的 Miniforge Prompt，讓 PATH 設定重新載入。

步驟 2-3：確認 Git 是否安裝成功

輸入位置：Miniforge Prompt

git --version

成功時會看到類似：

git version 2.xx.x.windows.x

只要有顯示 Git 版本，就代表 Git 已經可以使用。

步驟 2-4：如果還是顯示找不到 git

先完全關閉 Miniforge Prompt，再重新開啟一次。如果仍然無法辨識，可檢查 Git 是否真的安裝在：

C:\Program Files\Git\cmd\git.exe

若檔案存在，通常代表安裝成功，但 PATH 尚未正確載入；重新登入 Windows 或重新開機後再執行：

git --version
注意 GitHub 網址格式：
正確寫法是： 
https://github.com/OpenDrift/opendrift.git
不要寫成： 
https\://github.com/OpenDrift/opendrift.git
網址中的 https:// 前面不需要反斜線。

3. 移動到要放 OpenDrift 的資料夾

本教學後續全部使用 Miniforge Prompt。假設你要把 OpenDrift 放在：

F:\opendrift\program

輸入位置：Miniforge Prompt

cd /d F:\opendrift\program

成功後，提示字元會變成：

(base) F:\opendrift\program>

查看目前資料夾內容請用：

dir
Miniforge Prompt 是 CMD 介面，所以不要使用 dir。
另外，從 C 槽切到 F 槽這種跨磁碟機操作，請使用 cd /d。

4. 從 GitHub 下載 OpenDrift

先確認 Git 可以使用：

輸入位置：Miniforge Prompt

git --version

如果有顯示版本號，接著確認目前位置是：

(base) F:\opendrift\program>

然後執行：

git clone https://github.com/OpenDrift/opendrift.git

下載完成後，OpenDrift 會在：

F:\opendrift\program\opendrift

接著移動進去：

cd /d F:\opendrift\program\opendrift

再輸入：

dir

確認有看到：

environment.yml
examples
opendrift
tests
pyproject.toml

5. 建立 OpenDrift Python 環境

現在提示字元應該是：

(base) F:\opendrift\program\opendrift>

先確認 mamba 可以使用：

輸入位置：Miniforge Prompt

mamba --version

例如顯示：

2.5.0

再確認 environment.yml 確實存在：

dir environment.yml

確認無誤後建立環境：

mamba env create -f environment.yml

這一步會下載並安裝 OpenDrift 所需的 Python 與科學運算套件，因此可能需要一些時間。

6. 啟用 OpenDrift 環境

輸入位置：Miniforge Prompt

conda activate opendrift

成功後，提示字元前面會多出：

(opendrift) PS F:\opendrift\program\opendrift>
之後每次重新開啟 Miniforge Prompt，要使用 OpenDrift 前，都要先執行： 
conda activate opendrift

7. 安裝 OpenDrift 本體

確認你目前同時符合兩件事情：

項目應該看到
Python 環境(opendrift)
目前資料夾F:\opendrift\program\opendrift

再執行：

輸入位置：已啟用 opendrift 的 Miniforge Prompt

pip install --no-deps -e .

-e . 代表將目前這個 OpenDrift 原始碼資料夾以「可編輯模式」安裝。

8. 測試安裝是否成功

輸入位置：已啟用 opendrift 的 Miniforge Prompt

python -c "import opendrift; print(opendrift.__version__); print(opendrift.__file__)"

如果成功，會印出版本與套件位置，例如：

1.14.x
F:\opendrift\program\opendrift\opendrift\__init__.py

9. 查看官方案例資料夾

因為我們採用 Git 版本，所以官方案例已經一起下載。

輸入位置：Miniforge Prompt

cd /d F:\opendrift\program\opendrift\examples

列出案例：

dir

如果要找 OpenOil：

dir *openoil*

10. 建立自己的研究工作資料夾

官方原始碼和自己的研究案例建議分開。

回到上一層：

輸入位置：Miniforge Prompt

cd /d F:\opendrift\program

建立自己的專案：

mkdir My_OpenOil_Project
cd My_OpenOil_Project
mkdir scripts
mkdir input
mkdir output
mkdir figures

最後的結構會是：

F:\opendrift\program\
├─ opendrift\               ← 官方 OpenDrift 原始碼
│  ├─ examples\
│  ├─ opendrift\
│  └─ environment.yml
│
└─ My_OpenOil_Project\      ← 你自己的研究
   ├─ scripts\
   ├─ input\
   ├─ output\
   └─ figures\
之後我們真正做 Delft3D 流場、OpenOil 原點追蹤與油污案例時，建議全部放在 My_OpenOil_Project，不要直接修改官方 examples。

11. 從 Total Commander／一般 CMD 啟用 Miniforge

不一定要從 Windows 開始功能表開啟 Miniforge Prompt。你也可以先在目前工作資料夾開一般 CMD，再手動啟用 Miniforge。

適合 Total Commander 使用：
先在 Total Commander 進入你的案例資料夾，再從該位置開 CMD。這樣 CMD 一開始就會停在目前案例路徑。

步驟 11-1：先開一般 CMD

例如你目前案例在：

F:\opendrift\program\pratice\test-constantcurr

CMD 開啟後可能會看到：

F:\opendrift\program\pratice\test-constantcurr>

步驟 11-2：啟用 Miniforge base 環境

如果 Miniforge 安裝在：

C:\Users\user\miniforge3

在 CMD 輸入：

輸入位置：一般 CMD

call C:\Users\user\miniforge3\Scripts\activate.bat

成功後，前面會出現：

(base) F:\opendrift\program\pratice\test-constantcurr>

步驟 11-3：切換到 OpenDrift 環境

接著輸入：

conda activate opendrift

成功後會變成：

(opendrift) F:\opendrift\program\pratice\test-constantcurr>

步驟 11-4：直接執行案例

python example_constant_current.py

因此整個流程可以簡化成：

Total Commander
        ↓
進入案例資料夾
        ↓
開 CMD
        ↓
call ...\miniforge3\Scripts\activate.bat
        ↓
conda activate opendrift
        ↓
python xxx.py
這種方式的優點是：你不需要另外開 Miniforge Prompt，也不用重新切換資料夾；可以直接從 Total Commander 當前位置開始工作。
如果你的 Windows 使用者名稱不是 user，或 Miniforge 安裝在其他位置，請把： 
C:\Users\user\miniforge3
改成你自己的實際安裝路徑。

12. 每次重新開機後怎麼開始？

之後不用重新安裝。你可以直接開啟 Miniforge Prompt，或依上一節從一般 CMD 啟用 Miniforge。

輸入位置：Miniforge Prompt

conda activate opendrift
cd /d F:\opendrift\program\My_OpenOil_Project

然後執行自己的 Python 程式，例如：

python scripts\test.py

13. 完整安裝流程總覽

安裝 Miniforge 與 Git 完成後，後續全部都在 Miniforge Prompt 執行：

輸入位置：Miniforge Prompt

mamba --version
git --version

cd /d F:\opendrift\program

git clone https://github.com/OpenDrift/opendrift.git

cd /d F:\opendrift\program\opendrift
dir

mamba env create -f environment.yml

conda activate opendrift

pip install --no-deps -e .

python -c "import opendrift; print(opendrift.__version__)"
第一次操作建議一行一行執行。每一步成功後再進行下一步，出錯時比較容易知道問題出在哪裡。

快速啟動 OpenDrift 案例

如果你已經在案例資料夾開啟一般 CMD，之後每次只要依序輸入：

call C:\Users\user\miniforge3\Scripts\activate.bat

conda activate opendrift

python XXX.py

其中：

指令用途
call C:\Users\user\miniforge3\Scripts\activate.bat啟用 Miniforge。
conda activate opendrift切換到 OpenDrift 專用環境。
python XXX.py執行你的 OpenDrift Python 程式；把 XXX.py 換成實際檔名。

例如：

call C:\Users\user\miniforge3\Scripts\activate.bat
conda activate opendrift
python example_constant_current.py
依 OpenDrift 官方安裝文件整理。版本與相依套件可能隨官方更新而變動。
